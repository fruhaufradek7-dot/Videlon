# Videlon

**YouTube po svém. Bez reklam.**

Neoficiální aplikace pro Android pro sledování videí, Shorts, kanálů a playlistů. Videlon nabízí přehrávání na pozadí, mini přehrávač a další užitečné funkce.

## ✨ Funkce

### 🎬 Sledování videí
- Přehrávání běžných videí a YouTube Shorts.
- Vyhledávání videí a kanálů.
- Prohlížení kanálů, playlistů a komentářů.
- Mini přehrávač při procházení aplikace.
- Přehrávání na pozadí.

### 📺 Kanály a playlisty
- Zobrazení videí a Shorts na stránkách kanálů.
- Procházení playlistů a přehrávání jejich obsahu.
- Odebírání kanálů bez nutnosti přihlášení.
- Přehled odběrů a nových videí.

### 🛠️ Další možnosti
- Rozhraní inspirované aplikací YouTube pro Android.
- Podpora světlého a tmavého vzhledu.
- Další funkce podle aktuální verze aplikace.

## 📥 Stažení

Nejnovější dostupné sestavení najdeš v sekci [Releases](https://github.com/fruhaufradek7-dot/Videlon/releases).

Pokud zatím není zveřejněná nová stabilní verze, můžeš sledovat také sestavení projektu v [GitHub Actions](https://github.com/fruhaufradek7-dot/Videlon/actions).

Aplikace se instaluje mimo obchod Google Play. Android proto může při instalaci požádat o povolení instalace z daného zdroje.

## 💻 Pro vývojáře

Videlon je založený na Flutteru a jazyce Dart.

Zdrojový kód je rozdělen do částí pro uživatelské rozhraní, přehrávání, vyhledávání, kanály a další funkce aplikace.

### Základní příkazy

```bash
flutter pub get
flutter run
```
